## **Steps to reproduce the experiments described in the paper "Mixed Newton Method for Optimization in Complex Spaces"**

- **Positive polynomials minimization.** The notebooks
  - `experiments/positive_polynomial/OrdinaryNewton_RMNM_gamma_sweep on real subspace Ex 4.1.ipynb`
  - `experiments/positive_polynomial/OrdinaryNewton_RMNM_gamma_sweep on real subspace Ex 4.2.ipynb`
  - `experiments/positive_polynomial/OrdinaryNewton_RMNM_gamma_sweep on real subspace Ex 4.3.ipynb`
  - `experiments/positive_polynomial/OrdinaryNewton_RMNM_gamma_sweep-on complex subspace Ex 4.3.ipynb`

  contain numerical experiments for the comparison of the Ordinary Newton Method (ONM) and the Regularized Mixed Newton Method (RMNM) in terms of the minimization of nonnegative real polynomials.
- **Telecommunication task simulations.**

    1. **_Remarks related to both CV-CNN and RV-CNN models:_**
        - Folders `experiments/CVCNN` and `experiments/RVCNN` contain the `config.yaml` file, which includes 2 parameters provided to the user for adjustment: `device` and `chunk_num`.
        - `chunk_num` parameter relates to the number of chunks to divide the whole signal into and accumulate the hessian and gradient. This parameter is introduced in order to regulate the occupied GPU memory for the hessian calculation. It is recommended to set the number of chunks such that the whole signal length is divisible evenly by the number of chunks for correct hessian and gradient accumulation. The whole signal length equals 170800 complex samples.

    2. **_Simulations on CV-CNN model:_**
        In folder `experiments/CVCNN`:
        - Run `run_CMNM.py` to reproduce results achieved by Cubic Mixed-Newton method.
        - Run `run_CNM.py` to reproduce results achieved by Cubic Newton method.
        - Run `run_HCNM.py` to reproduce results achieved by Hermitian Cubic Newton method. HCNM replaces the second-order term of the Taylor expansion of the objective with a Hermitian form.
        - Run `run_LM_MNM.py` to reproduce results achieved by Mixed-Newton method with Levenberg-Marquardt adaptive regularization control.
        - Run `run_LM_NM.py` to reproduce results achieved by Newton method with Levenberg-Marquardt adaptive regularization control.
        - Results provided by authors are included in `experiments/CVCNN/results` folder.
        - Reproduced results, generated by run-files, will be saved in `experiments/CVCNN/reproduced_results` folder.
        - `experiments/CVCNN/plot_results.ipynb` calculates min-max range and mean curves on the basis of the calculated results and plots the corresponding graphs shown in the paper.
    3. **_Simulations on RV-CNN model:_**
        In folder `experiments/RVCNN`:
        - Run `run_CNM.py` to reproduce results achieved by Cubic Newton method.
        - Run `run_LM_NM.py` to reproduce results achieved by Newton method with Levenberg-Marquardt adaptive regularization control.
        - Results provided by authors are included in `experiments/RVCNN/results` folder.
        - Reproduced results, generated by run-files, will be saved in `experiments/RVCNN/reproduced_results` folder.
        - `experiments/RVCNN/plot_results.ipynb` calculates min-max range and mean curves on the basis of the calculated results and plots the corresponding graphs shown in the paper.

- **Abalone task simulations.** Simulations on both real-valued and complex-valued MLP models:
    In folder `experiments/MLP`:
    - Run `run.ipynb` to reproduce simulations related to all considered optimization methods: LM-MNM, CMNM, LM-NM, CNM, HCNM.
    - Run `plot_results.ipynb` to plot the corresponding graphs shown in the paper.
    - Results provided by authors are included in `experiments/MLP/results` folder.
    - Reproduced results, generated by run-file, will be saved in `experiments/MLP/reproduced_results` folder.
    - `experiments/MLP/plot_results.ipynb` calculates min-max range and mean curves on the basis of the calculated results and plots the corresponding graphs shown in the paper.
